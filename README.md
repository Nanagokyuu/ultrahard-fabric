# Ultra Hard（超困难）

适用于 **Minecraft 26.2** 的 Fabric + Kotlin 模组。新增真正的难度枚举值 **Ultra Hard（超困难）**，与和平/简单/普通/困难并列，基于困难并附加更严苛规则。

## 依赖

请一并安装：

- [Fabric Loader](https://fabricmc.net/use/) ≥ 0.19.5
- [Fabric API](https://modrinth.com/mod/fabric-api)（`0.160.0+26.2` 或更高的 26.2 兼容版本）
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) ≥ `1.13.12+kotlin.2.4.0`
- Java 25+

## 安装

1. 安装 Fabric Loader（Minecraft 26.2）。
2. 将本模组 jar 与上述依赖放入 `.minecraft/mods`。
3. 启动游戏。

## 构建

需要 **JDK 25**。

```bash
./gradlew build
```

产物位于：`build/libs/ultrahard-1.0.0.jar`（不含 `-sources`）。

## 启用超困难

与原版难度相同，可在以下位置选择：

### 创建新世界（开始游戏）

在「创建新世界」→ 游戏选项页的 **难度** 循环按钮中，与和平 / 简单 / 普通 / 困难并列出现 **超困难 / Ultra Hard**。选中后会写入世界的 `LevelSettings` / `WorldData`（序列化键为 `ultrahard`），开局即为超困难。

### 游戏内命令（需要权限等级 2 / OP）

```text
/difficulty ultrahard
```

也可使用 `/difficulty peaceful|easy|normal|hard` 切回其它难度。

### 游戏内选项菜单

在世界选项中的难度循环按钮里选择 **超困难 / Ultra Hard**。

## 效果说明（服务端权威）

当世界难度为 **Ultra Hard** 时：

1. **基于困难**：原版 Hard 相关行为均生效（僵尸增援、蜘蛛增益、饥饿致死等）。
2. **无自然回血**：取消饱食度/饱和度带来的自然恢复（类似 `naturalRegeneration false`）；药水等其它治疗仍可用。
3. **饥饿加快**：玩家饥饿值消耗（exhaustion）默认 × 1.25；连续超过两个游戏日没有进食后提高到 × 1.75。
4. **随进度强化的敌人**：获得任意一件铁盔甲前敌对生物保持原版伤害；获得后为 × 1.5；获得过任意一件钻石盔甲后为 × 2。头盔、胸甲、护腿、靴子均可，背包中或已穿戴的护甲都计入，附魔和耐久不影响判定。末影龙、凋灵和监守者始终保持原版伤害。
5. **敌对生物攻击软上限**：友好生物和 PvP 不受影响。攻击敌对生物时，伤害达到其最大生命值的 25% 后，超出部分仅保留 25%，最终向下取整。例如 20 点生命的怪物，9 点伤害会变为 6 点。触发时会显示特殊粒子。
6. **装备耐久减半**：工具、盔甲和盾牌的有效耐久减半，即每次耐久消耗翻倍；金制工具与金制盔甲不受影响。
7. **袭击八波**：第八波固定生成 4 个掠夺者、4 个卫道士、2 个女巫、2 个唤魔者、3 个劫掠兽；三只劫掠兽分别搭载唤魔者、掠夺者和卫道士。胜利后每位村庄英雄固定获得吸血 III 附魔书，并额外获得附魔金苹果或不死图腾各 50% 概率之一。
8. **睡眠恢复**：按主世界昼夜日期，每昼夜最多治疗一次，连续睡眠至少 5 秒（100 游戏 tick）才结算。入睡前生命值 ≥ 10 点（5 颗心）时，睡眠后直接回满；入睡前低于 10 点时恢复固定 10 点生命（可配置），且本次不能跳夜。中途起床会重新计时；同昼夜反复睡眠不会重复治疗。所有参与睡眠的玩家都入睡前达到 10 点、睡满 5 秒，并满足原版睡眠人数规则后可跳夜并清除天气；跳夜本身不额外提供治疗。治疗在跳到次日之前结算，次日重新获得治疗次数。

### 吸血附魔

- 可附加在剑和斧上，最高正常等级为 III，且不与其它附魔冲突。
- I / II / III 分别将本次攻击经过护甲减免后的伤害的 20% / 30% / 40% 转化为玩家生命值；IV 级为 50%，之后每级增加 10%，IX 级达到 100% 后不再增加。
- 本次攻击伤害仍受 Ultra Hard 的单次 25% 目标最大生命上限限制。
- 吸血仅对敌对生物生效；回复量向下取整，但每次至少恢复 1 点生命值，每秒最多触发一次；同一时间攻击多个敌人时，取最大有效伤害计算。治疗直接触发原版生命值图标的回复跳动效果。
- 沙漠神殿宝箱会额外尝试生成吸血附魔书：I 级 5%、II 级 4%、III 级 3%。
- 可通过 `/give @p minecraft:enchanted_book[stored_enchantments={levels:{"ultrahard:lifesteal":4}}]` 获取 IV 级；将等级数字改为更高值即可获取更高等级。

9. **敌人装备**：Ultra Hard 下敌人生成护甲的概率为原版的 1.5 倍。
10. **敌对生物战术 AI**：
   - 僵尸会从目标身后包抄；同一目标附近有两只以上僵尸时会前后夹击，未持武器者会为持武器者让出前排。
   - 骷髅会维持至少 4 格距离，提高射击精度；玩家举盾时会先从侧面绕到玩家背后再射击，不会朝盾牌正面射击；玩家转身后会重新寻找背后位置。僵尸会稳定分配前排和绕行单位。
   - 苦力怕开始引爆后，附近敌对生物会撤离爆炸范围；蜘蛛攻击命中玩家后会在其脚下生成蜘蛛网。
   - 女巫保持后排，优先治疗受伤的掠夺者、卫道士、唤魔者和劫掠兽；玩家接近时依次投掷虚弱、缓慢和伤害药水。
   - 敌对生物的互相伤害会被取消，避免误伤转移仇恨；所有亡灵白天会寻找水或阴凉处。

## 配置

旧存档升级说明：原来的铁锭/钻石进度和按运行 tick 记录的睡眠日期不沿用。护甲进度会按当前持有或穿戴的装备重新判定，此后继续永久记录；睡眠治疗次数改为按主世界昼夜日期记录。蜘蛛网为临时控制效果，同一玩家有冷却时间，生成后会自动消失。

首次启动后会生成 `config/ultrahard.json`。其中包含本模组使用的全部数值：饥饿和未进食阈值、攻击软上限、各进度的敌人伤害、耐久和敌方装备倍率、睡眠治疗、吸血、沙漠神殿宝箱、第八波的兵种数量和奖励概率，以及僵尸、骷髅、苦力怕、女巫、亡灵避阳等 AI 的距离、速度、精度和更新频率。

修改该文件后重启游戏或服务器即可生效。配置由服务端判定，联机玩家不需要单独修改。
